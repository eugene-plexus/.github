# .github

Default community files for every repository in the
[eugene-plexus](https://github.com/eugene-plexus) organization. A repository's
own file, when it has one, takes the place of the one here.

- [`SECURITY.md`](SECURITY.md): how to report a vulnerability privately.

Issue forms live in [`specs`](https://github.com/eugene-plexus/specs/issues/new/choose):
GitHub did not apply org-default issue forms here (2026-10-18).
